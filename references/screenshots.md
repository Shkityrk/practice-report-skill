# Скриншоты: техника

## Два типа кадров

1. **Терминальный кадр** — `Shooter.shot(page, "NN-имя.png", "Заголовок окна", [команды])`: команды выполняются
   на самом деле, вывод рисуется как окно тёмного терминала (1180 px), лог пишется в `notes/NN-имя.log`.
   Плюсы: воспроизводимо, без случайных данных рабочей машины, можно подменить подпись команды.
2. **Браузерный кадр** — `Shooter.browser_shot(page, "NN-имя.png", url, width, height)`; интерактив (заполнить форму,
   нажать кнопку) — обычным Playwright API (`page.fill`, `page.click`) между кадрами.
   Для длинных страниц (длинные веб-интерфейсы, детальные страницы) — высокий viewport (`height=2200`), а не
   `full_page` (в SPA с внутренним скроллом он часто обрезает).

## Правила

- Порядок кадров = порядок в методичке, имена `01-…`, `02-…` — сортируются так же, как идут в отчёте.
- Один кадр — один смысл; 1–5 команд, вывод не длиннее ~45 строк (длинное — `| head`, но в подписи команду
  показывать как есть: `shown` без `| head`, если это не искажает смысл).
- `(команда, "как показать")` — когда реальная команда содержит секрет/локальный порт/абсолютный путь. Подменяется
  ТОЛЬКО подпись: вывод остаётся настоящим, поэтому команда не должна печатать секрет (брать значение внутри
  целевой среды (контейнера, сервиса) или подстановкой `$(…)`, фильтровать `| egrep`). Всё, что всё-таки может попасть в вывод (имя рабочего контекста,
  токен, адрес), перечислить в `Shooter(..., redact=[…])` — такие строки заменяются на «<скрыто>» в подписи, выводе и
  `notes/*.log`. Результат команды не искажать.
- Команды с «вечным» выводом (команды, которые держат терминал или открывают браузер) запускать в фоне с `--url`/логом,
  кадр делать из лога, процесс потом гасить.
- Если методичка требует интерактива, невозможного в headless, — делать эквивалент и честно писать это в тексте
  («для отчёта использован ключ --url»).
- Нужен «чистый старт»: перед съёмкой удалить пробные ресурсы и данные (иначе в кадрах будут старые «возраст 8 мин» и лишние объекты).
- Брать готовый Chromium: `find_chrome()` (версия Playwright часто ждёт билд, которого нет; скачивать новый — только
  с согласия пользователя).
- После съёмки — открыть 3–5 ключевых PNG и посмотреть (Read): обрезка, пустой вывод, секреты, кадры с незавершёнными процессами.

## Пересъёмка одного кадра

Маленький одноразовый скрипт: `import shots` из `report/`, поднять только нужное состояние, снять, вернуть как было.
Не гонять всю последовательность ради одного кадра.
