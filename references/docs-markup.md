# Разметка документов при ведении работы + ссылки на другие скиллы

Всё, что агент ведёт «вокруг» отчёта, — обычный Markdown в папке работы. Три файла, у каждого своя роль.

## PLAN.md — договор с пользователем (до работы)

Заголовки второго уровня, таблицы для требований и отступлений, чек-лист в конце. Образец — `templates/PLAN.md`.

```markdown
## Что требуется (по методичке)
| # | Требование | Источник |
|---|---|---|
| T1 | Запустить сервис из локального образа (имя по варианту) | стр. 3 |

## Отступления от методички
| Что в методичке | Что сделано | Почему |
|---|---|---|
| образ `tool:1.0` из методички | `tool:1.2` | старый тег недоступен/не собирается |
```

Правила: каждое требование получает номер и потом закрывается рисунком/абзацем; «Что нужно от вас» — нумерованный
список вопросов пользователю; изменения плана по ходу — в тот же файл, а не в чат.

## notes/ — доказательства (во время работы)

Один `.log` на скриншот, формат без украшений: `$ команда` → вывод → пустая строка. Пишет `Shooter` автоматически.
Это источник правды для текста отчёта (цифры, имена, статусы берутся отсюда, а не по памяти).

## Отчёт — `report/build_report.py`

Структура — `references/report-structure.md`; код разметки — методы `Report` (`heading`, `sub`, `para`, `figure`,
`table`, `code`, `bullets`, `sources`). Пример фрагмента:

```python
r.sub("2 Название этапа")
r.para("Сервис запущен командой … (что делаем и зачем).")
r.figure("03-run.png", "Запуск сервиса")
r.para("Значение поля … означает …")
```

## Когда звать другие скиллы

Важно! Если ты - Codex/Grok/Deepseek/GLM - используй не anthropic-skills, а подбери скилл такой же, как anthropic-skills. Поищи в интернете, при необходимости - установи.

| Задача | Скилл |
|---|---|
| Править уже готовый .docx (замена текста, комментарии, правки) | `anthropic-skills:docx` |
| Читать/склеивать PDF, формы, извлекать таблицы | `anthropic-skills:pdf` |
| Составить подробный пошаговый план реализации (код/инфра) | `superpowers:writing-plans` |
| Перед «готово» — проверить фактами, а не словами | `superpowers:verification-before-completion` |
| Паттерны по теме работы (контейнеры, оркестрация, БД и т.д.), если подходящий скилл есть в списке сессии | например `ecc:docker-patterns`, `ecc:kubernetes-patterns` |
| Актуальная документация библиотеки/CLI | `ecc:documentation-lookup` |
| Проверка веб-части в браузере | `ecc:browser-qa` |
| Допрос по плану, если требования неясны | `grill-me` |
| Создать документ в Claude Docs вместо docx | `anthropic-skills:docs` |

Если нужного скилла нет в списке сессии — не придумывать название, сделать вручную.
